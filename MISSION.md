# Mission: Superpowers Skills For Software Development

## Why

Learn how to use the Superpowers skills as a repeatable software-development workflow, from early idea shaping through design, implementation, review, and publication. The goal is to know which skill to invoke, when to stop for user approval, and what artifact should exist before moving to the next phase.

## Success looks like

- Choose the right Superpowers skill for each phase of a software project.
- Drive a project from concept to published PR without skipping design, tests, review, or verification gates.
- Explain when to use subagent-driven development versus inline plan execution.
- Keep the workflow lean and avoid ceremony when a smaller artifact is enough.

## Constraints

- Teach in Spanish.
- Prefer practical, workspace-backed lessons over abstract explanations.
- Keep materials small enough to review quickly.

## Out of scope

- Building a full training platform.
- Exhaustive documentation of every installed skill.
- Tool-specific deep dives not needed for the core software-development lifecycle.
